# Приложение «Заявки» для сисадминов (Android)

Оболочка вокруг вашего сайта + фоновая проверка заявок. Никаких Firebase и серверных функций не нужно.

## Сборка
1. В `app/src/main/java/com/hotel/zayavki/Config.kt` впишите адрес вашего сайта (с https:// и слэшем в конце).
2. На github.com создайте приватный репозиторий и загрузите все файлы этой папки (включая скрытую `.github`).
3. Вкладка Actions → «Build APK» → Run workflow. Через 3–5 минут скачайте архив `hotel-app` внизу страницы запуска, внутри `app-debug.apk`.
4. Установите APK на телефон (разрешите установку из неизвестных источников).

## Первый запуск
1. Откройте приложение, **войдите** под своим логином (если вы уже были авторизованы, нажмите «Ещё» → «Выйти» и войдите заново).
2. Разрешите уведомления и работу в фоне.
3. В «Ещё» → «Уведомления и будильник» настройте переключатели и время будильника.
4. В шторке появится тихое уведомление «Слежение за заявками включено», его нужно оставить.

## Если уведомления не приходят при выключенном экране
Телефоны Xiaomi, Huawei, Samsung и др. сами «усыпляют» приложения. Откройте настройки приложения «Заявки»:
разрешите автозапуск, а для батареи выберите «Без ограничений».
